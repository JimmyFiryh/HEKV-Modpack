# Jimmyserver Competition Modpack Repository

This repository exists as an easy way for the Jimmyserver showrunners to create and share updates to a common shared modpack meant for fighter jet competitions.



Why not CKAN?

&nbsp;	- We often make modifications to the base mods for competition balance. As such, it's rather annoying to tell people to make 30 changes to each mod folder. This used to be distributed as a .zip file on discord. It could be worse. 



Does this violate licenses?

&nbsp;	- I hope it doesn't. This is merely for distribution to a very niche amount of competition players. All licenses are included in their original folders. I and any local contributors do not take credit for any mod that isn't made by us. 



If you would like to complain about licensing or this distribution existing, DM me @firyh on discord and we can work something out.
